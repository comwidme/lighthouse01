# 등대독서회 홈페이지

㈜제주비 사내 독서동호회 ‘등대독서회’를 소개하는 반응형 단일 페이지 홈페이지입니다.

## 주요 내용

- 동호회 소개와 참여 가치
- 함께하는 독서 활동
- 정기모임 일시·장소·참가대상
- 처음 참여하는 임직원을 위한 안내
- 참여 및 문의 정보 영역

## 실행

Node.js 22.13 이상이 필요합니다.

```bash
npm install
npm run dev
npm run build
npm test
```

가입 담당자 또는 사내 메신저 채널이 확정되면 `app/page.tsx`의 “참여 및 문의” 영역을 실제 정보로 교체하세요.
